# Print matrix

Every bundled city at three wall widths. Print time = sum of sliced plate times (0.2 mm layers, 2 walls, 8 % infill, PLA). Farm columns = wall-clock with that many printers running in parallel, 8 min between plates. Cost = filament at $22/kg. Assembly = hands-on time model (2.5 min per tile, 1.5 min per line piece, ~0.3–0.8 min per station/label part, +15 %).
